# HyperCortex 变更记录

## 未发布

- 未知笔记面类型改为快速失败：新建与保存接口提交非法面类型时直接报错，不再静默丢弃；校验在产生任何磁盘副作用之前完成。
- 附件上传源文件缺失时报错明示「源文件不存在」，不再误报为附件不存在。
- 新建收藏夹与收藏条目的标识格式与界面侧统一（36 进制毫秒时间前缀 + 随机后缀），不再两套格式并存。
- 笔记版本标识内嵌时间改用本地时间，与界面展示一致（原先内嵌 UTC，差 8 小时）。
- 新增收藏夹语义写入口（建夹 / 改夹 / 放入 / 移出 / 挪夹）：调用者只表达意图，后端内部读改写并统一带防覆盖保险丝（expectedVersion），写入成功回传新版本；放入校验目标真实存在，收藏夹引用拒绝自引用与环。
- 新增笔记元数据增量入口：只改提交的标题 / 简介 / 标签字段，缺失沿用旧值，与保存接口共用同一防覆盖保险丝。
- 新增附件同步上传入口：复用现有上传管道，一次调用等待全部落盘后直接返回附件编号与引用标记，不产生界面用的上传任务记录。
- 面顺序与面设置两个既有入口补上防覆盖保险丝：与笔记 / 收藏夹同语义，写入成功回传新版本标记。
- 调整索引页失效引用卡片交互：点击卡片本体不再直接清理引用，避免误触删除。
- 保留失效引用的明确清理入口：进入编辑状态后，通过卡片右上角菜单清理。
- 补充失效引用卡片说明文字，使提示与当前交互一致。
- 顶部栏「收藏夹」右侧新增「全局关系图」入口：用 canvas 渲染全仓库笔记的全局关系图，节点取自笔记索引（含无引用的孤立笔记）、边取自引用索引；支持滚轮对着光标缩放、拖空白处平移、悬停高亮节点及其直接邻居、拖动节点时重加热仿真、点击节点跳转到对应笔记，并提供斥力与往中心收的紧凑度两个布局参数调节。该页与主页 / 收藏夹 / 附件 / 全部笔记走同一套页面机制，可在设置里自由选择独立页面或模态窗。
