# HyperCortex 变更记录

## 未发布

- 新增收藏夹语义写入口（建夹 / 改夹 / 放入 / 移出 / 挪夹）：调用者只表达意图，后端内部读改写并统一带防覆盖保险丝（expectedVersion），写入成功回传新版本；放入校验目标真实存在，收藏夹引用拒绝自引用与环。
- 新增笔记元数据增量入口：只改提交的标题 / 简介 / 标签字段，缺失沿用旧值，与保存接口共用同一防覆盖保险丝。
- 新增附件同步上传入口：复用现有上传管道，一次调用等待全部落盘后直接返回附件编号与引用标记，不产生界面用的上传任务记录。
- 面顺序与面设置两个既有入口补上防覆盖保险丝：与笔记 / 收藏夹同语义，写入成功回传新版本标记。
- 调整索引页失效引用卡片交互：点击卡片本体不再直接清理引用，避免误触删除。
- 保留失效引用的明确清理入口：进入编辑状态后，通过卡片右上角菜单清理。
- 补充失效引用卡片说明文字，使提示与当前交互一致。
