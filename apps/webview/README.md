# webview

webview 是 Fast Window v5 应用体系中的**独立收藏桌面与浏览 App**：把网址收藏以桌面图标的形式管理（分组、收纳夹、壁纸、图标外观），点击图标以内嵌「浏览栈」打开网页，并内置网页视频倍速能力。

桌面界面移植自 `apps/folders`（收藏集）的整套桌面体验，但只保留**网址**一类收藏；数据由 webview 自己的 Rust 壳命令管理，不依赖 folders 的 Go 后端与其数据文件体系。

## 功能

- **收藏桌面**：桌面图标网格（列数自适应、网格吸附）、拖拽摆放（默认自动让位、按住 Ctrl 自由覆盖）、图标缩放与间距设置。
- **分组**：新增、改名、删除（级联搬迁）、拖拽排序、快捷导航（Ctrl+↑/↓ 与 Ctrl+滚轮），选择记忆。
- **收纳夹**：桌面收纳夹图标（计数 + 迷你预览）、全屏展开面板、标题就地重命名、拖入（悬停自动展开、精确落点）、拖出到桌面、拖到条目上自动成夹、删除释放条目。
- **图标外观**：网页图标嗅探（多候选逐个发现 + 进度 + 首个自动选中）、选择本地图片、粘贴剪贴板图片、8 色板默认图标。
- **壁纸**：本地图片导入、多预设切换与删除、取景编辑（平移 / 缩放 / 重置）。
- **设置面板**：桌面图标布局 + 壁纸管理 + 视频倍速设置（合并为同一面板），数据目录信息与切换。
- **内嵌浏览栈（多页面）**：点击网址打开"顶部栏 + 网页内容"双窗口浏览器；每次打开新建独立页面（同一收藏可重复打开），页面互不影响、后台页面继续播放；顶部栏布局：最左为「主页」长按钮（图标在左 + 文字，点击回主窗口），与后退 / 前进 / 倍速之间留出间隔；居中为当前页面切换按钮（左右两侧提供上一个 / 下一个页面切换键，点击展开页面列表可切换页面、单独关闭某个页面）；最右为刷新 / 图钉 / 全屏 / 隐藏 / 关闭。位置记忆，失焦自动收起，Windows 底部圆角。
- **主窗口与浏览窗口双向往返**：网页顶部栏"回主窗口"收起浏览栈但不关闭页面；桌面顶部栏在有页面时显示"返回网页"按钮，回到浏览栈当前页面。
- **网页视频倍速**：默认倍速 + 最大倍速 + 预设（可绑定快捷键，网页内按快捷键切换/还原），顶部栏速度菜单可循环切换；倍速随页面记录，切换页面时各页显示各自速率。
- **多账号身份**：同一网址可右键「新建账号身份」派生独立图标（右下角带专属角标），各自拥有独立的浏览器登录空间，同一网站可同时登录多个账号；身份图标与普通条目同权（改名、编辑、拖拽、分组、收纳夹、搜索）；删除时可选择是否清除其登录数据（保留的数据可在设置里检测清理）；编辑图标时可按网址继承已有身份的登录状态；默认账号（原条目）与所有普通条目共享原有登录状态。
- **旧书签平滑升级**：首次启动自动把旧书签转成桌面条目（默认分组、原顺序、本地图标迁移为图标资产），旧文件原样保留作为备份。

## 窗口结构

| 窗口 | label | 职责 |
|---|---|---|
| 主窗口 | `main` | 收藏桌面（含顶部栏与设置面板） |
| 浏览栈顶部栏 | `browser_bar` | 浏览按钮条、页面切换下拉与速度菜单 |
| 浏览栈内容 | `browser-<n>` | 加载外部网页（每个页面一个独立窗口） |

## 数据与配置

数据目录由 App 运行位置自动计算（`package/` 同级 `data/`；exe 不在 `package/` 时用 exe 同目录 `data/`）：

- `collections.json`：收藏数据主文件（工作区 = 分组 / 条目 / 收纳夹 / 桌面状态 + 界面状态，`dataVersion` 为 2，旧版 1 首次启动自动升级；数据版本过高时拒绝启动以保护数据）。
- `assets/icons/`：图标资产（内容哈希命名，写入幂等）。
- `assets/wallpapers/`：壁纸资产（同上）。
- `bookmarks.json`、`bookmark-icons/`：旧书签数据与旧图标目录；升级完成后原样保留作为备份。
- `app.json`：应用配置（`webview` 视频倍速设置、`browserWindowBounds` 浏览栈位置记忆）。
- `browser/`：浏览器数据（网页登录状态、Cookie、会话、缓存）；主窗口、顶部栏与全部浏览页面共用这一份，跟随数据目录切换（重启生效）。
- `browser-profiles/`：多账号身份各自的浏览器数据空间（每个身份一份，含来源元数据 `identity.json`；删除身份条目时按选择清理，仅当没有其他条目共享该空间时才真正清除）。
- `webview-settings.json`：用户自选数据目录（App 配置目录内）。

浏览器数据的历史位置为系统用户目录（`%LOCALAPPDATA%\com.fastwindow.webview\EBWebView`）：升级后的首次启动会自动一次性搬入 `browser/`（先复制完整、再就位、最后清空旧位置；任何一步失败都会保留旧位置并在下次启动重试，不会搬丢数据）。

Go sidecar 骨架仍由模板机制接管（`settings.json`、`_meta.json`、`_migrations.json` 由其负责），收藏业务不经过 sidecar。

## 平台命令

| 命令 | 用途 |
|---|---|
| `open-webview` | 打开收藏桌面 |
| `open-settings` | 打开设置面板 |
| `show-health` | 打开收藏桌面（Go 骨架健康状态） |

## 开发命令

```powershell
pnpm --dir apps/webview build:backend
pnpm --dir apps/webview test:ui
pnpm --dir apps/webview apps:version:check
pnpm --dir apps/webview apps:bump:dry
go test ./...   # 需在 apps/webview/backend-go 目录执行
pnpm --dir apps/webview exec tsc --noEmit
cargo check --manifest-path apps/webview/src-tauri/Cargo.toml
cargo test --manifest-path apps/webview/src-tauri/Cargo.toml
pnpm --dir apps/webview exec vite build
pnpm --dir apps/webview build:exe:dev
```

## 构建命令

```powershell
pnpm --dir apps/webview build:app:dev
pnpm --dir apps/webview build:app
```

`build:app:dev` 用于生成本地开发版应用容器（`apps/webview/dist-app/v5-windows-dev/`），`build:app` 用于生成本地正式版容器（`apps/webview/dist-app/v5-windows/`）。

## 手工验收清单

- 独立启动显示主窗口与托盘；关闭按钮隐藏到托盘。
- 桌面：图标拖拽摆放（默认让位 / Ctrl 覆盖）、搜索过滤、空态引导、右键菜单（新建 / 新建收纳夹 / 新建分组）。
- 分组：新增 / 改名 / 删除 / 拖拽排序 / 顶部切换 / Ctrl+↑↓ 与 Ctrl+滚轮导航；上次分组自动恢复。
- 收藏项：新增 / 编辑 / 删除；移动到分组、复制到分组、粘贴剪贴板网址快速创建并自动获取图标。
- 收纳夹：拖入（悬停展开、精确落点）、拖出到桌面、拖到条目上自动建夹、删除释放条目、面板内排序、标题重命名。
- 图标外观：网页图标多候选逐个出现并自动选中首个；选择图片、粘贴图片、默认色板、清除自定义。
- 壁纸：添加 / 切换预设 / 取景编辑 / 删除 / 清除；桌面实时生效。
- 设置：图标布局滑块即时生效；视频倍速设置保存后浏览窗口即时生效。
- 点网址图标打开内嵌浏览栈；顶部栏关闭/隐藏/回主窗口/全屏/图钉/后退/前进/刷新可用；移动记忆位置；失焦自动收起（图钉后不收起）。
- 多页面：连续打开收藏会新建页面并自动切换；顶部栏下拉按打开顺序列出页面（图标 + 名称），点击切换、小叉单独关闭；关闭当前页自动切到相邻页；关闭最后一页回到主窗口。
- 顶部栏布局：左侧为「主页」长按钮与后退 / 前进 / 倍速（主页与其余按钮留间隔），右侧窗口控制组顺序为刷新 / 图钉 / 全屏 / 隐藏 / 关闭；中央页面切换按钮左右两侧可循环切换已打开页面（只有一个页面时禁用）。
- 双向往返：浏览栈"回主窗口"收起后页面保留；桌面顶部栏"返回网页"回到当前页面；全部关闭后该按钮隐藏。
- 后台页面音视频继续播放；切换页面时窗口位置大小不跳动；倍速修改作用于当前页面并随切换显示各自速率。
- 旧书签首次启动自动迁移进桌面（名称、网址、顺序、本地图标保留）；旧 `bookmarks.json` 与 `bookmark-icons/` 仍在。
- 浏览器数据归拢：打开网页后数据落在数据目录 `browser/`；系统用户目录不再产生 `EBWebView`（旧数据首次启动自动搬入，登录态保持）。
- 多页面登录态互通；设置里切换数据目录并重启后，登录态跟随到新目录。
- 多账号身份：右键网址图标新建身份，桌面出现独立图标；两个身份分别登录不同账号互不干扰、重启后各自保持；身份图标可改名/拖拽/分组/收纳夹；删除身份后其登录数据被清除、重建为未登录。
- 多账号身份跟随数据目录：切换数据目录并重启后，默认账号与所有身份的登录态一并跟随。
- 身份角标：身份图标右下角显示专属角标，与普通图标一眼可分。
- 删除身份：确认框可勾选是否清除登录数据；取消勾选后数据保留，可在设置「孤立登录空间」中检测到并清理。
- 编辑继承：编辑同一网址的其他图标时，可选择继承某个已存在的登录身份（含未绑定的登录数据）。
- 数据目录不可写 / 数据版本过高时主窗口显示错误提示；可切换数据目录。
- FW 启动行为（show/hide/toggle/close、bounds 上报、命令分发 open-webview/open-settings/show-health）与 v5 模板一致。
- 重复启动转发到已有实例；dev/release 互不串实例。

## 与模板的关系

- 派生自 `apps/v5-reference-app-go`（v5 Go sidecar 模板），模板壳模块（single_instance / fw_window / control_server / standalone_tray / data_dir / shutdown / backend_lifecycle / backend_sidecar）保留，仅做身份替换。
- 业务数据层：`src-tauri/src/collections/`（模型与校验、文档读写、旧书签迁移、资产导入、网页图标发现、业务方法与统一命令）。
- 前端桌面界面：`src/collections/`（从 `apps/folders` 移植并按网址单类精简；数据通道改为 Tauri invoke + 资产经 asset protocol 呈现）。
- 浏览栈扩展为多页面：`browser_stack.rs`（顶部栏 + `browser-<n>` 页面窗口集合与当前页指针）/ `browser_commands.rs`（打开、切换、单页关闭、往返、面板高度等命令）/ `BrowserBarApp.tsx`（页面切换下拉与窗口按钮）；点条目打开新页面由 `collections.items.open` 承接（带条目名称与图标）。
- 宿主（`src/`、`src-tauri/`）与插件（`plugins/web-view/`）零改动。
